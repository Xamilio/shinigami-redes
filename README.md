# Shinigami Couture (Redesigned)

Современный интернет-магазин в стиле брутализм. Проект реализован на ванильном стеке с интеграцией Supabase для управления контентом и пользователями.

## Технологии
*   **Frontend:** Чистый HTML5, CSS3 (Custom Properties) и JavaScript (ES6+).
*   **Backend:** Supabase (Database, Auth, Storage).
*   **Fonts:** Outfit (Google Fonts).

## Основные возможности
*   **Дизайн:** Строгий ч/б интерфейс, кастомная анимация курсора, прелоадер и плавная бегущая строка.
*   **Магазин:** Динамический каталог товаров, корзина на `localStorage` сDrawer-интерфейсом.
*   **Админка:** Полноценный CRUD для товаров, управление настройками сайта и медиа-библиотекой.
*   **Локализация:** Поддержка нескольких языков (UK/EN и др.) через кастомную систему i18n.

## Структура проекта
*   `admin/` — интерфейс и логика панели управления.
*   `product/` — динамическая генерация страниц товаров.
*   `profile/` — кабинет пользователя.
*   `supabase-config.js` — конфигурация подключения к бэкенду.
*   `main.js` — основная логика фронтенда и работы с корзиной.

## Как запустить
1. Настроить ключи доступа в `supabase-config.js`.
2. Поднять любой локальный сервер (например, Live Server в VS Code или `npx serve .`).
